## Round 3 requirements verification

### 1. Public ID formatting (`c_` + 32-hex Keel ID)
- Public card IDs leaving the package consistently use `"c_" + [0-9a-f]{32}` across all egress points:
  - `Store.Put` returns `"c_" + rawID`.
  - `Store.PutWithAlternatives` returns `mainID = "c_" + rawMain` and `altIDs[i] = "c_" + rawAlts[i]`.
  - `Store.Latest` returns `"c_" + rawID`.
  - `Store.Recent` yields `Summary.ID = "c_" + rawID`.
  - Stored card payload body has `$.id` set to `"c_" + rawID`.
  - Relinked alternative cards have `main.Alternatives[i].CardID` set to `"c_" + rawAltID`.
- SQLite storage key:
  - The SQLite table column `cards.id` remains the raw 32-hex Keel ID (`^[0-9a-f]{32}$`), preserving indexing and database storage efficiency while ensuring the outside never sees bare hex.

### 2. Pre-query refusal on closed database
- In `internal/cards/cards.go`, `Store.Get` validates:
  ```go
  raw, ok := strings.CutPrefix(pubID, "c_")
  if !ok || !id.Valid(raw) {
      return pipeline.Card{}, ErrNotFound
  }
  ```
- Bare hex (`^[0-9a-f]{32}$`), invalid prefixes (`j_...`, `x_...`), fixture-style non-hex IDs (`c_7Hq2mXv9pK3wLr8sTn4bYe`), empty strings, SQL injection strings, and invalid lengths are refused with `cards.ErrNotFound` before executing any SQL query.
- Verified on a closed database connection: invalid IDs return `ErrNotFound` without querying the connection, whereas a valid format (`c_` + 32-hex) attempts the query and returns `sql: database is closed`.
