## Judgements, not findings

- **Spin-offs are skipped.** `sameTitle` skips spin-offs and other titles that contain the name: "Roblox Studio" for Roblox, "Minecraft Dungeons" for Minecraft. They come from the same publisher and platform, so they are poor "safer alternatives" anyway. Accepted. A one-word generic title would skip more ("Sky Garden" for "Sky"). That is acceptable for the demo titles.
- **A hit whose name drags in a sentence is dropped.** "Calm Builder review: is it safer than Roblox?" contains the title, so it is dropped. Its name would have been garbage anyway, so this is accepted.
- **Pending user decisions, kept as they are.** A feed error does not fall back to the store page. Alternatives versus `checks_daily` is left to P4. Refused alternatives stay shown.
