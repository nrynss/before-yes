## Prior findings verification (round 1)

Zero residue across all round 1 findings:

### H1 (High): Thin / uncacheable evidence cached when expired entry exists
- **Remediation:** In `internal/server/cache.go`, `flightState` tracks `st.putCalled` and `st.putPayload`. When `p.Collect` skips calling `p.Cache.Put` on thin or failed evidence, `st.putCalled` remains false. `maker` returns `uncacheableEvidenceError` directly without querying `c.store.Get`. Keel's `GetOrMake` receives the error and does not write to the store, leaving any existing expired SQLite row untouched. In `Collect`, `errors.As(err, &ue)` unpacks the collected evidence and returns `(ue.ev, hit, nil)`.
- **Pin:** Verified via `TestExpiredEntryNotOverwrittenByThinEvidence` and independent external measurement against `/tmp/h1_test.db` with `sqlite3`:
  1. Populated cache entry for "Roblox" at `t0` (timestamp `1791972000000000000`, 555 bytes payload).
  2. Advanced clock by 2 hours past 1-hour `MaxAge`.
  3. Re-collected with `failExtract = true`, producing thin evidence (`missingKinds = [policy terms]`).
  4. Queried SQLite directly via `sqlite3`: `SELECT key, created_at, length(payload) FROM evidence_entry` confirmed `created_at` remained `1791972000000000000` (unchanged) and payload remained 555 bytes.
  5. Subsequent `ec.Get(ctx, key)` returned `ok = false, err = nil`.
- **Status:** Resolved. Zero residue.

### M1 (Medium): Unbounded in-memory map leak in `activeFlights`
- **Remediation:** In `internal/server/cache.go`, `Collect` assigns each caller an atomic token (`c.seq`). A deferred function unregisters `c.activeFlights[key]` when `st.leaderToken == myToken`. This runs on all return paths: clean completion, uncacheable evidence, pipeline errors, and decoding failures.
- **Pin:** Verified via `TestActiveFlightsDoesNotLeak`:
  1. 100 sequential collects across distinct titles: `activeFlightsCount()` was 0 after each collect.
  2. Error collect (searcher failure): `activeFlightsCount()` remained 0.
  3. Thin evidence collect: `activeFlightsCount()` remained 0.
  4. Concurrent collect across 10 goroutines (`TestConcurrentIdenticalChecksCollectOnce`): `activeFlightsCount()` was 0 upon completion.
- **Status:** Resolved. Zero residue.

### L1 (Low): Redundant double-write to SQLite store on cache miss
- **Remediation:** When `p.Collect` calls `p.Cache.Put`, `EvidenceCache.Put` checks `c.activeFlights[key]`. If present, it stages the marshalled payload in `st.putPayload` without issuing a store write. Keel's `storeResult` then performs the single durable `store.Put` on completion. Direct calls to `Put` outside `Collect` continue to write directly to `store`.
- **Pin:** Verified via `TestCacheMissSingleStorePut` with `recordingStore`:
  1. A cold collect for "Roblox" invoked `store.Put` exactly 1 time (previously 2).
- **Status:** Resolved. Zero residue.
