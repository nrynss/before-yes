## Findings

| ID | Sev | Finding | Pin |
|---|---|---|---|
| M1 | M | Advice steps are rejected only by a closed denylist of starting verbs. Any other imperative gets through as a candidate. The page `1. Download the app / 2. Open settings / 3. Disable chat` gives `[Download the app, Open settings]`. Each one takes a slot, costs a full `Collect` (about eight Tavily credits and a reader pass), and is shown as an alternative's title. This is the same cost and slot problem as round-2 M1, now on a smaller set of inputs. To fix it, require a positive signal for a numbered entry on a page that is not a ranked list: for example, bold or link markup, a title-case shape, or a check that the page's numbered entries look like a ranking and not a how-to. Or reject any entry whose first word is a lowercase-continued imperative, then pin it with this page. | Throwaway probe on `listNames` (deleted) |
| L1 | L | False negatives on real titles. `notAName` matches common first words of real titles, so those titles are dropped without a sound: `Stop Motion Studio`, `Read Along by Google` and `Pick a Path` are all rejected (from `1. Stop Motion Studio / 2. Read Along by Google / 3. Pick a Path / 4. Toca Kitchen`, only `Toca Kitchen` comes through). Other examples: "Top Eleven", "Make It Rich", "Learn with Homer". Dropping a candidate costs nothing and only lowers recall, so this is low severity. It should be kept in mind if the denylist grows to cover M1. | Same probe |
