## Findings

| ID | Sev | Finding | Pin |
|---|---|---|---|
| M1 | M, open | Refused names are hidden only on the `WithAlternatives` path. The phase file names a second P4 hook: "`FindAlternatives` followed by `CheckAlternatives` when the pending list should be shown first". On that path the card first shows every candidate as `pending`, so a name the cap later refuses has already been on the card and in the API. `CheckAlternatives` then returns `AltResult.Alternatives` with the refused entries (`status: refused`), and the filter that hides them, `shown`, is unexported. The contract still allows `"status": "refused"` on a card's alternative. The decision "a refused name doesn't leak anywhere in the card or the API" is therefore not enforced at the boundary P4 is told to use. Fix: make `CheckAlternatives` (or an exported helper) return the shown list and the note, and either drop the pending-first hook or say that pending names are shown before the cap decides. | alternatives.go `CheckAlternatives`, `shown`; PHASE-3 T3.5 notes, "The P4 hook" |
| L1 | L, open | No test covers a meter refusal (Tavily or model) in the middle of a fresh alternative's check while `Checks` is set. That path should call `Fail`, so the reservation is released and not booked, and mark the rest refused. The code does this (`_ = hold.Fail()`, then `capped = false`), but nothing pins it. That leaves part of the "cap is not double-counted / refusal mid-list" decision untested. | alternatives_test.go: only cap refusals and the no-`Checks` budget refusal are tested |
| L2 | L, accepted | `cached()` and `Collect` look up the cache separately. If an entry is evicted between them, a fresh collect runs with no reservation, and the reverse case books one check too many. The memory cache never evicts, and the durable cache is T4.2. | alternatives.go `cached` |
| L3 | L, accepted | When `hold.Done()` returns an error, a card that was already made is dropped, and its spend is booked. The checks_daily store failing is rare, and dropping the card is the conservative choice. | alternatives.go, the `hold.Done()` branch |
