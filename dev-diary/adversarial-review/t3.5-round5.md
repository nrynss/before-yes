## Judgements, not findings

- **Gaming corroboration.** An advice step becomes a candidate only if the same response has a single-title hit with that name, for example a page titled "Disable chat". That hit would be a candidate anyway through `candidateName`, so the list path adds no exposure. `titled` is built only from hits that `candidateName` accepts. A list title fails `listicle`, so it corroborates nothing. Accepted.
- **What the list path now contributes.** Every list name is also a single-title hit, so the list path can only bring a name forward in order. It does this when the list page ranks before the corroborating hit, or when that hit falls after the cap. This is the accepted trade-off recorded in feedback.md, not residue.
- Unmarked or uncorroborated list pages give nothing. Accepted trade-off.
- Pending user decisions, not blocking: alternatives versus `checks_daily` (P4), and refused alternatives being shown.
