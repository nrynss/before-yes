## Attacks on the fix

- **Join-only is race-free.** The lookup, the cache recheck and the refusal all happen in one critical section, and `done` needs the same lock to remove an entry. No path from a `joinOnly` request reaches `admit` or `StartKind`.
- **Visitors.** `joinsRunning` is false for any visitor-key request, so a visitor request is never marked join-only; with live off it is refused at the gate, as before. The `joinOnly` refusal sits outside the `!visitor` block, so it would still refuse there.
- **An unreadable switch fails closed.** `flags.Bool` errors set `on = false`. A joiner may still join (it costs nothing), and nothing new starts.
- **The cache recheck cannot return a wrong card.** It uses the same `Fresh(title, age)` call and key as the first read, so it returns only a fresh card for this title and age, or nothing.
- **Live flipping mid-request.** See A4.
