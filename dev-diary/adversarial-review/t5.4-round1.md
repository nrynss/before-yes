### L1. Route ID validation accepts noncanonical card IDs

`cardID` accepts any nonempty sequence of letters, digits, `_`, and `-` after `c_`. The Go producer emits exactly `c_` plus 22 base-62 characters (`internal/pipeline/pipeline.go`, `newCardID`). In a standalone browser pin, `/card/c_1` passed the client route check and issued `GET /api/cards/c_1` (one API call), although it cannot be a producer-generated ID. Validate the complete producer format so malformed route IDs do not reach the API. This is low severity because the accepted alphabet remains path-safe and the request returns the ordinary not-found state.
