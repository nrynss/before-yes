## Findings

### L1 (accepted, carried from round 2). Invented claims can carry a pasted run of a real quote
Unchanged. This is a limit of checking after the reply, and it is recorded as an open item.

### L2 (accepted). The setting check is bag-of-words
Every content word must appear in the quote, but order and adjacency don't matter. "Turn on Ask to Buy" is backed by the mitigation quote "You can ask friends what to buy." "Settings > Privacy > Chat" is backed by "Chat with friends; privacy settings are public." For this to happen, the quote must be verified, in the same area, read as a mitigation, and contain every content word of the setting. The reason must also carry a run of a cited quote, and the quote is shown on the card. The round-2 loophole, where a generic phrase backed an invented control, is closed. Accepted. Requiring the content words in order inside a short window is a possible follow-up.

### L3 (accepted). Negation is not seen
"There is no spending PIN." backs the setting "spending PIN" if the reader marked it as a mitigation. A reason that negates a pasted run still names its quote. This is the same class as L1: string checks can't read meaning. Accepted.
